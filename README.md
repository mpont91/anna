# Anna

Anna's birthdays, one page per year, gathered in one site: a landing with every
birthday, and each one at its own path (`/29`, `/30`, `/31`, `/32`).

Astro + Vue + Tailwind, TypeScript, Node 26 (see `.nvmrc`), npm workspaces.

```sh
make install   # dependencies
make dev       # http://localhost:4321
make check     # format, lint, typecheck and build
```

How it's organised, and how to add next year's birthday, is in `CLAUDE.md` and
`apps/web/CLAUDE.md`.
